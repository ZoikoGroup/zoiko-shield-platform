BUG-01: Past notifications delivered 4–5 hours earlier are not returned by Notification search

Module

Overview &gt; Notifications

Status

Open

Description

While searching past notifications in the Notification Inbox (All notifications tab), notifications delivered 4–5 hours earlier are not displayed.

The inbox returns “No records match the current filters” even though the header counter shows 3 records and a notification is listed as selected.

Search should return previously delivered notifications; as it stands, users cannot look up or review recent alerts.

Figure 1: Notification Inbox shows “No records match the current filters” for the search term.

BUG-02: No information displayed in the Findings section

Module

Detect &amp; Investigate &gt; Findings

Status

Open

Description

The Findings page loads with all counters (Open, Stale assertions, Ageing, Unscored, Scored over unknowns, Unresolved asset) showing “unknown”.

Module

Status

Description
