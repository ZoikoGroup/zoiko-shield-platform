**Scope Clarification on User Instruction ("emails, messages, and downloads"):**
- **Email & email attachments (downloads inside Mail/providers):** Covered directly in Doc 1 §05–§06 and Doc 2 §01–§17.
- **Collaboration/instant messaging, shared file links, calendar invitations & broader downloads:** Placed in **Workstream C / P2 discovery scope** (Doc 1 §03, §06.4, §14 `C01`; Doc 2 §01 "OUT / separately approved"). Standalone consumer AV / endpoint download agent is explicitly rejected ("No independent consumer antivirus product", Doc 1 Executive Decision & §01; Doc 2 §01). See [open-questions.md](file:///c:/Users/aparaziitha%20nitta/zoiko-shield-platform/docs/open-questions.md) for manager clarification on messaging and non-email downloads.

> **Priority Legend:** `P0` = Release-blocking Zoiko Mail foundation or required Shield Phase 0 pilot control | `P1` = Subsequent differentiated detection / policy write capability | `P2` = Separately gated expansion (post-delivery remediation, collaboration/files).
